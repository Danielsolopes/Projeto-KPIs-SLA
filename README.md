Projeto de Business Intelligence — Análise de Vendas
Documentação de KPIs para uma solução de BI voltada à performance comercial.

📌 Sobre o Projeto
Estruturar uma solução de Business Intelligence para a área comercial, com foco em previsibilidade de vendas, otimização de resultados e suporte à decisão estratégica.

🗂️ Canvas do Projeto
Categoria	Descrição
Objetivos	• Previsibilidade de vendas
• Organizar tempo e resultados
• Melhorar performance do time
• Campanhas mais assertivas
Fonte dos Dados	SQL Server, Excel
Meta	Faturamento por gerente e categoria, com sazonalidade entre trimestres
Stakeholders	Gerentes, Supervisores, Vendedores, Diretor
Usabilidade	Facilidade com apps/sites • Preferência por dark mode
📈 KPIs
KPI	O que mede
Faturamento	Receita total no período
Quantidade de Vendas	Volume transacionado
Ticket Médio	Valor médio por venda
Metas	Alcance vs. objetivo por gerente/categoria
🎯 Objetivo Final
Entregar uma solução de BI com:

Previsibilidade de vendas por gerente, categoria e sazonalidade

Visibilidade de desempenho individual e por equipe

Insights para campanhas mais assertivas

Interface dark mode alinhada ao perfil do cliente

🧰 Tecnologias
Camada	Ferramenta
Fonte	SQL Server, Excel
